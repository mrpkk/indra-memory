# indra-memory

## Когда применять

- Агент работает долго и теряет факты между шагами
- Нужно зафиксировать решение с датой и важностью
- Нужно собрать контекст по теме задачи **под жёсткий бюджет токенов**
- Нужно понять, что изменилось после предыдущего решения

## Четыре команды, которых достаточно

```bash
memory remember "факт" --tags слой,продукт --importance 5
memory recall "что знаю про мост" --with-links
memory pack "мост" --tokens 800
memory link 12 закрывает 3
```

## Три правила

**1. Важность — 1..5.** Ставится руками. 5 = это меняет решение,
1 = заметка для себя. Поиск по умолчанию берёт всё от 1, но сортирует по важности.

**2. Версия, а не замена.** Факт изменился — не перезаписывай, а:
```bash
memory supersede 12 "новый текст"
```
Старый факт станет `superseded` и уйдёт из поиска, но останется в истории.
Через полгода станет понятно, почему решение было таким.

**3. Контекст собирается запросом, а не чтением подряд.**
```bash
memory pack "текущая задача" --tokens 800
```
Вернёт только релевантное, вместе со связанными фактами. **Бюджет жёсткий** —
сколько фактов ни накопилось в базе, в контекст влезает ровно заданное.

## Чего инструмент не делает

- **Не ищет по смыслу** — только по словам. Спроси «мост» — найдёт про
  эскроу, если в тексте есть слово. Спроси «доверие» без слова «мост» — нет.
- **Не помнит термы короче 3 букв** через полнотекстовый индекс (идут через
  LIKE, работает).
- **Не удаляет физически.** `forget` помечает статус, запись остаётся.

## Пример цикла

```bash
# 1. узнал что-то
memory remember "x402: ETH не нужен, газ платит фасилитатор" \
  --tags x402,крипто --importance 5

# 2. связал с уже известным
memory recall "газ" -k 1                 # узнал id
memory link <новый> подтверждает <старый>

# 3. собрал контекст под задачу
memory pack "платежи агентов" --tokens 600

# 4. факт изменился
memory recall "x402" -k 1
memory supersede <id> "фасилитатор PayAI, не Coinbase"
```
